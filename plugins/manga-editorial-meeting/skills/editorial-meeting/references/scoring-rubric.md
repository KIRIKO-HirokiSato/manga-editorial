# 4軸スコア採点基準（ジャンル対応版）

## 軸1: コアの面白さ（What's the hook?）

「一言で言うと何が面白い？」が明確か。ジャンルは問わない。面白さの核が言語化できているか。

| スコア | 基準 |
|--------|------|
| 9-10 | 一言で面白さを説明でき、聞いた人が「読みたい」と即座に思う。核が独自性と普遍性を兼ね備えている |
| 7-8 | 面白さの核は明確。「ありそうでなかった」感がある。ただし説明に少し言葉が要る |
| 5-6 | 面白さはあるが、核がぼんやりしている。「何が面白いの？」と聞かれると答えに詰まる |
| 3-4 | 面白さの核が不明確。設定や世界観の説明に終始している |
| 1-2 | 何が面白いのかが伝わらない。または面白さの核が存在しない |

### ジャンル別の見方

| ジャンル | コアの面白さで見るべきポイント |
|----------|------------------------------|
| バトル・冒険 | 主人公の目標と成長の道筋。「何のために戦うか」が明確か |
| ギャグ・コメディ | 笑いの構造（ボケの型・ツッコミの切れ）。笑いの核が言語化できるか |
| ヒューマンドラマ | 人間関係の核にある感情的な問い。「この人の人生を見たい」と思えるか |
| 日常系 | 「この世界にいたい」と思わせる空気。世界観そのものが面白さの核 |
| 恋愛 | 二人の関係の核にあるドキドキの構造。「くっつくかどうか」以上の何かがあるか |

## 軸2: 第1話の力（Does page 1 grab you?）

1話で読者を掴む設計ができているか。ジャンルごとに「掴み方」は異なる。

| スコア | 基準 |
|--------|------|
| 9-10 | 冒頭3ページで心を掴む。世界観の提示と物語の推進が自然に両立。最後のコマで「次を読みたい」が確定 |
| 7-8 | フックが効いている。読者の好奇心を刺激する謎がある。次話への期待が生まれる |
| 5-6 | フックはあるが弱い。説明に頼りすぎ or 掴みが遅い |
| 3-4 | フックが不明確。1話を読み終えても「で、何？」となる |
| 1-2 | 読者を引き込む要素がない。または1話の構成が破綻 |

### ジャンル別の見方

| ジャンル | 第1話で掴む方法 |
|----------|----------------|
| バトル・冒険 | 衝撃的な事件・能力の覚醒。主人公の日常が壊れる瞬間 |
| ギャグ・コメディ | 冒頭3ページで笑わせられるか。笑いのテンポ |
| ヒューマンドラマ | 「この人の人生を見たい」と思わせる導入。感情的な問いかけ |
| 日常系 | 世界観の提示と小さな驚き。「この場所に来てよかった」感 |
| 恋愛 | 出会いの瞬間の設計。二人の間に走る最初の火花 |

## 軸3: 連載の持続力（Can it run for 10+ volumes?）

2巻、5巻、10巻と続くエンジンがあるか。「面白いけど3話で終わる」を防ぐ。

| スコア | 基準 |
|--------|------|
| 9-10 | 対立が3段階以上。エピソード生成の種が豊富。50話以上の展開が自然に見える |
| 7-8 | 連載の方向性が見える。20-30話分のネタが想像できる。パワーインフレ対策がある |
| 5-6 | 短期的には面白いが、持続力に疑問。ネタ切れの兆候が見える |
| 3-4 | 読み切り向き。連載として展開する構造がない |
| 1-2 | 1話で完結。拡張の余地がない |

### ジャンル別の見方

| ジャンル | 持続力の源泉 |
|----------|-------------|
| バトル・冒険 | 敵の階層（3段以上）・仲間の段階的加入・能力の成長段階 |
| ギャグ・コメディ | ネタの再生産構造・キャラの掛け合いの幅。1パターンだけでは持たない |
| ヒューマンドラマ | 人間関係の展開余地・テーマの深化。新たな関係性の投入 |
| 日常系 | マンネリを防ぐ変化の種。季節イベント・新キャラ・日常が揺らぐ瞬間 |
| 恋愛 | 「くっつくまで」の障害の段階設計。恋愛以外のサブプロットの充実度 |

---

## 軸4: 時代との接点（Why now?）

今の読者に届くか。類似作品との差別化。

| スコア | 基準 |
|--------|------|
| 9-10 | 今の時代だからこそ響くテーマ。類似作品との明確な差別化。「今これが読みたかった」感 |
| 7-8 | トレンドとの接点がある。差別化ポイントが1つ以上明確 |
| 5-6 | トレンドを意識しているが、差別化が不十分。「既視感がある」 |
| 3-4 | 時代性が薄い。類似作品との差別化が見えない |
| 1-2 | 市場に出す意味が見えない。完全に既存作品の下位互換 |

### ジャンル別の見方

| ジャンル | 時代との接点で見るべきポイント |
|----------|------------------------------|
| バトル・冒険 | 能力バトルの差別化。今の読者が求める主人公像 |
| ギャグ・コメディ | 今の読者の笑いのツボ。SNS 時代の口コミ力 |
| ヒューマンドラマ | 社会的な共感ポイント。今の時代の悩み・問い |
| 日常系 | 読者の「癒し」ニーズとの接点。現実逃避先としての魅力 |
| 恋愛 | 恋愛漫画トレンドとの差別化。現代の恋愛観の反映 |

---

## よくある落とし穴（ジャンル横断）

- 設定は面白いが「物語」がない（日常系に多い）
- 主人公に欠損がなく成長余地がない（バトル系に多い）
- 笑いの型が1パターンしかない（ギャグに多い）
- 対立を入れすぎて核がぼやける（全ジャンル共通）
- 「面白い設定を思いついた」で止まっている（全ジャンル共通）
