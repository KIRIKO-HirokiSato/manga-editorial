# 4軸スコア採点基準

## 軸1: 主人公エンジン（担当: character-editor）

主人公が物語を前に進める「エンジン」として機能するかを評価する。

| スコア | 基準 |
|--------|------|
| 9-10 | 動機が切実で普遍的。明確な弱点が成長弧を生む。読者が無条件に応援したくなる。感情移入の入口が複数ある |
| 7-8 | 動機と弱点が明確。成長の方向性が見える。感情移入できるが、独自性にやや欠ける |
| 5-6 | 動機はあるが弱い、または類型的。弱点が表面的。成長弧が予測可能 |
| 3-4 | 動機が不明確。弱点が設定されていない。読者が感情移入しにくい |
| 1-2 | 主人公の人物像が把握できない。物語を動かす力がない |

**チェックポイント:**
- 主人公はなぜ「今」行動を起こすのか？（動機の切実さ）
- 主人公の弱点は物語の障害として機能するか？（弱点の構造的意味）
- 読者は主人公のどこに自分を重ねるか？（感情移入の入口）
- 主人公は第1話で何を失う / 何を決意するか？（初動のインパクト）

## 軸2: 対立構造（担当: story-editor）

主人公と対立する力が、物語に緊張感と深みを与えるかを評価する。

| スコア | 基準 |
|--------|------|
| 9-10 | 対立が多層的（個人・組織・社会・内面）。敵にも共感できる論理がある。勝敗の予測がつかない |
| 7-8 | 明確な対立軸がある。敵の動機が理解できる。緊張感が持続する |
| 5-6 | 対立はあるが単純。敵が「悪いから悪い」に近い。展開が予測しやすい |
| 3-4 | 対立が曖昧。敵の存在感が薄い。緊張感が不足 |
| 1-2 | 対立構造が存在しない、または破綻している |

**チェックポイント:**
- 敵は主人公の「何」を脅かすか？（対立の本質）
- 敵にも正義はあるか？（対立の深み）
- 対立は段階的にエスカレートするか？（緊張の持続）
- 主人公は対立を通じて何を学ぶか？（対立の物語的意味）

## 軸3: 読者フック（担当: story-editor）

読者を物語に引き込み、次のページ・次の話を読ませる力を評価する。

| スコア | 基準 |
|--------|------|
| 9-10 | 第1話冒頭で心を掴む。毎話の引きが強い。「謎」と「期待」が同時に機能する。SNSで語りたくなる要素がある |
| 7-8 | 冒頭のフックが効いている。読者の好奇心を刺激する謎がある。次話への期待が生まれる |
| 5-6 | フックはあるが弱い。謎が表面的。読者の興味を持続させるのが難しい |
| 3-4 | フックが不明確。読者が読み続ける理由が薄い |
| 1-2 | 読者を引き込む要素がない |

**チェックポイント:**
- 第1話の最初の3ページで読者は何を感じるか？（初動フック）
- 第1話の最後のコマで読者は何を知りたくなるか？（引き）
- 「友達に勧めるとき、一言で何と言う？」（口コミ力）
- 読者が予測する展開と、実際の展開にギャップはあるか？（意外性）

## 軸4: 連載エンジン（担当: market-analyst）

週刊/月刊連載として長期間維持できる構造的な力を評価する。

| スコア | 基準 |
|--------|------|
| 9-10 | 敵の階層が3段以上。エピソード生成の種が豊富。キャラの成長余地が広い。50話以上の展開が自然に見える |
| 7-8 | 連載の方向性が見える。20-30話分のネタが想像できる。パワーインフレ対策がある |
| 5-6 | 短期的には面白いが、連載の持続力に疑問。ネタ切れの兆候が見える |
| 3-4 | 読み切り向き。連載として展開する構造がない |
| 1-2 | 1話で完結してしまう。拡張の余地がない |

**チェックポイント:**
- 敵の組織は何段階か？（階層構造）
- 主人公の能力にはどんな成長段階があるか？（パワーカーブ）
- 日常回・修行回・大会編など、エピソードの種類は何パターンあるか？（バリエーション）
- 30話時点で物語はどこにいるか？（中期ビジョン）
- 同ジャンルの成功作と比較して、連載構造はどうか？（市場比較）
