# 編集会議レポート テンプレート

以下のフォーマットでレポートを出力すること。

**★最重要ルール: 各編集者の発言は、その編集者の口調・人格をそのまま維持して記載すること。**
要約や言い換えで丁寧な分析文体にしてはならない。
熱血は熱血の口調（「！」多用、感情全開）、鬼軍曹は鬼軍曹の口調（短文、体言止め、感嘆符なし）、
目利きは目利きの口調（くだけた語尾、具体名で語る）、編集長は編集長の口調（「…」、静かな迫力）で書く。
レポートを読むだけで「誰が喋っているか」が一発でわかること。
